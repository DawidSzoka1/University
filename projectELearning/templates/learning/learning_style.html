03 Jak Ci idzie w poszczególnych stylach

System zapisuje, w której wersji przerabiasz lekcje, i porównuje wyniki testów zdawanych po nich. Polecenie pojawi się, gdy w danym stylu masz co najmniej dwa ocenione testy.

{% if analysis.kind == "switch" %}

Polecamy styl „{{ analysis.suggested.name }}”. Twoje testy po lekcjach w tym stylu wypadają lepiej niż w stylu „{{ analysis.current.name }}”. Wybierz go wyżej i sprawdź na kolejnych lekcjach.

{% elif analysis.kind == "choose" %}

Najlepiej idzie Ci w stylu „{{ analysis.suggested.name }}”. Nie masz wybranego stylu — wybierz go wyżej, a lekcje z wersjami dopasują się do Ciebie.

{% elif analysis.kind == "keep" %}

Twój styl „{{ analysis.current.name }}” sprawdza się najlepiej. Nie widzimy stylu, w którym szłoby Ci wyraźnie lepiej.{% if analysis.explore %} Jeśli chcesz porównać, przerób kilka lekcji w wersji „{{ analysis.explore.name }}”.{% endif %}

{% elif analysis.graded_attempts %}

Za mało danych na polecenie. Masz {{ analysis.graded_attempts }} {{ analysis.graded_attempts|pl_plural:"oceniony test,ocenione testy,ocenionych testów" }}, ale żaden styl nie ma jeszcze dwóch.{% if analysis.explore %} Spróbuj lekcji w wersji „{{ analysis.explore.name }}”, żeby było z czym porównać.{% endif %}

{% else %}

Jeszcze nie mamy czego analizować. Przerób kilka lekcji i rozwiąż testy — polecenie stylu pojawi się tutaj.

{% endif %}
